# DSA Lab 🐍

A collection of **Data Structures and Algorithms (DSA)** implementations and
lab exercises written in Python.

## Topics Covered

- **Linked lists:** singly, doubly, and circular linked lists
- **Stacks:** basic stack operations and postfix arithmetic evaluation
- **Queues:** standard and circular queues, dequeues, min-heaps, and max-heaps
- **Searching:** sequential, binary, and Fibonacci search
- **Sorting:** bubble, insertion, selection, merge, quick, and heap sort
- **Trees:** a binary search tree student-record exercise
- **Lab exercises:** sorting comparison and student-record management

## Requirements

- Python 3
- No external packages are required

## Getting Started

Clone the repository and move into the project directory:

```bash
git clone https://github.com/parthzraj/DSA-Lab.git
cd DSA-Lab
```

Most files are standalone scripts. Run a script from the repository root with:

```bash
python sorting/mergeSort.py
```

Several data-structure files are interactive programs and prompt for menu
choices, including the files in `stack/`, `queue/`, and
`linked_list/`. The lab exercises can be run with:

```bash
python labquestion/question1.py
python labquestion/question2.py
```

`question1.py` generates `generated_numbers.txt` and `sorted_numbers.txt`
when it runs. These files contain the input data and merge-sort output used by
the sorting comparison.
